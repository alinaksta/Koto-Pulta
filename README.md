# Koto Pulta

**Koto Pulta** is a university Capstone Project game.

This repository contains the game project files, source code, art assets, design settings, and documentation needed for development.

---

## Branches

This repository uses two long-term branches:

| Branch | Purpose                                                        |
| ------ | -------------------------------------------------------------- |
| `main` | Stable builds, milestone versions, presentations, and releases |
| `dev`  | Active development and team integration                        |

Most work should be done on short-lived task branches, then merged into `dev` using a pull request.

```text
task branch → dev → main
```

Do not push directly to `main`.
